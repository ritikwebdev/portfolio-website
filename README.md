# Ritik Kumar — Professional Portfolio

A recruiter-friendly, responsive portfolio website built with:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- Google Fonts

## Files

- `index.html` — complete website structure/content
- `style.css` — responsive design and animations
- `script.js` — navigation, scroll progress, active sections, back-to-top and form behavior
- `resume.pdf` — add your real resume PDF here

## Before publishing

1. Put your real `resume.pdf` in the same folder.
2. Replace the LinkedIn placeholder URL in `index.html` with your actual LinkedIn profile.
3. Add the correct GitHub URLs for each individual project.
4. Add live-demo URLs for Medicio and eStore when those projects are deployed.
5. If you want a PHP/MySQL contact form, move the contact form to PHP hosting. GitHub Pages only serves static files.

## Deploy on GitHub Pages

Upload `index.html`, `style.css`, `script.js` and `resume.pdf` to your repository root.

Then:

Settings → Pages → Deploy from branch → `main` → `/root` → Save

## Suggested project URLs

Keep your portfolio linked to your real project repositories and deployed demos. Do not use placeholder URLs in the final version.
